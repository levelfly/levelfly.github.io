# 嚕米的夜光島

給 3～6 歲小朋友的數字冒險。手機／平板優先，桌機也能玩。

## 兩座島

同一顆引擎（舞台、彈簧、粒子、程序生成美術、語音），兩套完全不同的島與玩法：

| 檔 | 島 | 動詞 | 學什麼 |
|---|---|---|---|
| `age4` 小小找光 | **夜光島**（深藍的夜、海、星星） | **找** | 聽數字找數字、數數量選數字 |
| `age6` 島嶼修復師 | **晨風群島**（日出、雲、風） | **分** | 把光分成幾群送出去 —— 8 可以是 5+3 也可以是 4+4 |

分開的理由不是難度調高。4 歲在「認」，6 歲在「分配」，那是兩個遊戲。

進場時兩扇門讓她自己選（左邊一盞提燈、右邊一張迎風的帆），畫面上不寫「4 歲 / 6 歲」——
那是大人的分類，而且被歸類成「小的那個」不會讓人想按。

兩座島各自完整：夜光島是「五個地點都亮 → 燈塔 → 結局」，
晨風群島是「一晚幾段風 → 風停天亮 → 明天再來」。存檔完全隔開，靜音與彩蛋共用。

## 怎麼跑

需要一個靜態伺服器（因為用了 ES modules，直接開 `index.html` 會被瀏覽器擋）。

```bash
cd 夜光島
python serve.py            # → http://127.0.0.1:8777
```

`serve.py` 只是關掉快取的 `http.server`，換成任何靜態伺服器都可以：

```bash
npx serve .        # 或
php -S 127.0.0.1:8777
```

**手機實機測試**：跟電腦同一個 Wi-Fi，把 `serve.py` 最後一行的 `127.0.0.1` 改成 `0.0.0.0`，
再用手機開 `http://<電腦IP>:8777`。或用 `/quick-tunnel` 開一條臨時 https 網址
（iOS Safari 的音訊在 http 也能跑，但加到主畫面全螢幕玩比較好）。

第一次進來會停在一盞提燈上——**點它**（瀏覽器規定要有一次真實觸碰才准出聲，
這一下同時也是遊戲的第一個動作）。

### 開發捷徑

```
?go=marsh|cove|grove|cliff|light     直接跳進某個地點（夜光島）
?go=garden|mill|falls|market|beacon  直接跳進某座島（晨風群島）
?go=map|title|agepick                直接跳場景（map 會自動去對應那個檔的地圖）
?go=lantern|nest|dawn|finale         收藏頁／窩／天亮／結局
?go=map&lit=marsh,cove               順便指定哪些地方已經點亮
?profile=age4|age6                   強制切年齡檔（指定了就不再問「想去哪座島」）
```

⚠️ `?go=garden` 這類捷徑要**搭配 `?profile=age6`**，否則會拿 age4 的地點清單去找、找不到。

### 走查

```bash
python tools/test_profiles.py     # 存檔分檔與 v1→v2 遷移（雙向）
python tools/test_skyisle.py      # 晨風群島：開場＋航線圖、fps、節點可點、配色
python tools/test_skyplay.py      # 晨風群島：真的拖著光珠走完一整晚（含守恆紅線）
python tools/test_single_file.py  # 單檔版 file:// 真的玩完一關（--http 切模組版對照）
python tools/test_level1.py       # 夜光島 marsh 一整輪
python tools/test_cycle.py        # 週目與難度變化
```

`tools/render_sky.html` 會把晨風群島的每個場景各生一張、直橫向都排出來，右上角顯示所有場景一起跑的 fps。

### 打成一個 HTML 檔

```bash
python tools/build_single.py     # → dist/夜光島.html，約 3.1 MB
python tools/test_single_file.py # 冒煙測試：真的開 file:// 玩完一關
```

雙擊就能玩、可以直接 AirDrop／LINE 傳給別人、沒網路也能跑。做法是 `bun` 把 38 個模組
打成一顆 IIFE、CSS inline、`assets/` 每個檔轉成 data URI，再裝一個十行的 `fetch`
攔截器把相對路徑導過去——**`src/` 一行都不用改**，程式碼不知道自己被打包了。

那個攔截器是必要的：`file://` 底下 fetch 相對檔案一定失敗（瀏覽器把它當 opaque
origin），語音會整組載不到、默默退回瀏覽器語音合成。

兩種發行版並存，各有各的用途：

| | 用途 | 存檔 |
|---|---|---|
| `index.html`（模組版） | GitHub Pages，加到主畫面全螢幕玩 | 可靠 |
| `dist/夜光島.html`（單檔） | 送人、離線、沒網路 | `file://` 下 iOS Safari 可能擋 localStorage，攔截器會退到記憶體版（能玩完，關掉就忘） |

`dist/` 不進 git（3MB 而且每次 build 都整包不同），要分享就現場 build。

## 玩什麼

夜光島的光被吹散了。小獸嚕米提著一盞空燈籠，需要小朋友幫忙把光找回來。
島上五個地方，每個地方 4～5 題，答完就永久亮起來，並帶回一隻光靈。
五個地方都亮 → 燈塔點燃 → 結局。

兩根學習支柱（題型會隨地點與表現輪替）：

| 題型 | 做什麼 | 出現在 |
|------|--------|--------|
| `listen` | 聽到一個數字，從畫面裡找到那個數字 | 貝殼海灘、星星懸崖、燈塔 |
| `count` | 看到一群東西，選出對應的數字 | 螢火沼澤、果實樹林、燈塔 |
| `quantity` | 聽到數字，選出「那麼多」的一群 | 燈塔 |

**難度會自己走**：連錯兩題 → 選項降到 2 個並提示正解；連對三題 → 選項升到 4 個、數字範圍放大。
答錯沒有紅色、沒有叉叉、沒有分數，那個東西只是害羞地縮一下，永遠可以再試。

**數數是可以用手的**：`count` 題裡每隻螢火蟲／每顆果子都能戳，戳一個亮一個，
木琴音一階一階往上，同時報「一、二、三……」。這是鷹架，不是答案。

## 晨風群島玩什麼（6 歲檔）

嚕米的燈籠裡有 N 顆光，島上幾個地方各自需要一些。她把光**分**過去。
同一個 8 可以是 5＋3，也可以是 4＋4 —— **每一種都對**。
（立論不是「難度調高」：數量守恆大約 6 歲才長出來，這個玩法正好踩在她剛長出來的能力上。）

需求全部用畫面講，**一個算式符號都沒有**：

| 槽 | 畫面上長什麼樣 | 學什麼 |
|---|---|---|
| 空位 | 幾個沒亮的位子 | 數量對應、湊十（剛好十格就畫成 5＋5 的十格框） |
| 一樣多 | 空盤子＋一條絲帶連到旁邊那一群 | 比較（要先數對面才知道自己要幾顆） |
| 剩下的 | 一個敞口的籃子 | 拿走多少、剩下多少 |
| 標價 | 價格牌上畫著光幣 | 1／5／10 換算 |
| 自由 | 一個柔邊的空碗 | 多解法分解（配方圖鑑的來源） |

五座島各綁一個數學骨架：雲上花園 `bond` ／ 風車島 `inverse` ／ 水瀑島 `diff` ／
晨風市集 `coin` ／ 晨鐘塔 `makeTen`。**出什麼題由教學導演決定**（`data/director.js`）——
每個骨架有自己的精熟層級，層級只會往上，不會因為今天狀況不好就掉回去。

**一晚＝一段航程。** 風吹 5～7 段就收帆回家，天色同步慢慢轉亮（那是進度條，不是計時器）。
每一段風只給兩個去處，路上會遇到分光地點、寶箱（挑一件道具）、光靈、休息。

### 三條不能碰的線

1. **光永遠守恆。** 分錯只是光珠飛回燈籠、化成一縷霧，嚕米說「我們換一種分法看看」。
   對 6 歲來說資源耗損會被讀成能力評價，「分錯 → 光變少」會直接翻譯成「我輸了」。
   `tools/test_skyplay.py` 每次都會故意分錯一次來驗這條。
2. **解鎖只能來自發現或作品，不能來自表現評級。** 4 歲檔的金色／彩虹光靈綁「零錯＋不亂點」，
   那是評級，**6 歲檔沒有搬**。光靈的花紋來自「她發現過幾種拆法」，而且只增加表達、不增加學習優勢。
3. **天色可以，倒數不行。** 可預期、可視覺化的進度提示降低焦慮；突然逼近的倒數誘發數學焦慮。

### 道具＝有撤除路徑的鷹架

十件道具（分光鏡、星星托盤、回音貝、小螃蟹、配對絲帶、月秤、湊十風箏、零錢袋、
退一步小船、配方書籤），每一件都會隨著對應骨架的精熟度**自己變得更含蓄**：

```
level 0  直接幫她做      分光鏡真的把光切成兩半
level 1  只給提示        分光鏡只畫出中線
level 2  只剩裝飾        它還在，只是不再替她想
```

撤除的說法不是「你長大了所以這個要拿走」——道具永遠不會被沒收。
唯一不升級的是**退一步小船**：它不是數學鷹架，是操作安全網（知道做錯可以退回來，
是她敢自己試的前提）。

### 沒有外部素材

畫面上每一個像素都是程式畫的：SVG 路徑 + `feTurbulence` 撕紙濾鏡 + Canvas 粒子。
沒有圖片檔、沒有字型檔、沒有 emoji、沒有第三方函式庫。
好處不只是輕——**程序化場景會動**（草會晃、水會湧、星星會呼吸），
而且直握橫握是「重新構圖」而不是「把桌面版縮小」。

### 效能：撕紙感放在幾何裡，不放在濾鏡裡

第一版跑起來只有 **12 fps**。逐層量測（`display:none` 一層測一次）指向同一個原因：
場景是一整張大 SVG，只要裡面有任何東西在動，整張就會重畫——**連同裡面每一個
`feTurbulence` 濾鏡**。當時場景裡有 60 個帶濾鏡的元素。

四刀砍到 **60 fps**，畫面幾乎沒有損失：

1. **場景與角色不用位移濾鏡**——不規則邊緣本來就長在 `tornEdge()` / `blob()` 產生的
   幾何裡，濾鏡只是再糊一層看不太出來的絨毛。濾鏡留給不會每幀重畫的小元件（數字牌、道具）。
2. **霧的柔邊改用漸層**而不是 `feGaussianBlur`——霧每幀都在飄，帶著模糊跑等於每幀重算一次大面積模糊。
3. **合併每幀的屬性寫入**：蘆葦分兩束整組搖（不是每根各搖）、水帶與浪頭同一個 `<g>`、
   只有最上面兩條水帶會動、會眨的星星設上限 18 顆。
4. **粒子改用烘好的 sprite**：每顆粒子即時 `createRadialGradient` 是手機殺手，
   現在每個顏色只烘一次 64×64 的小 canvas，之後都只是 `drawImage`。

道具的光暈也改成「彈簧停下來就不再寫屬性」——否則每幀寫一次 `opacity`
會讓整顆 prop 連同它的濾鏡重畫。

### 聲音

- **音效／配樂**：Web Audio 即時合成。木琴、玻璃風鈴、泡泡、光的綻放；
  配樂是一組緩慢的五聲和聲墊 + 隨機灑落的木琴音，每個地點換根音與音色，永遠不會 loop 到膩。
- **語音**：`assets/voice/*.mp3`，由 `manifest.json` 對照 id → 檔案。
  目前是 edge-tts 的 `zh-TW-HsiaoChenNeural`。**要換成真人錄音，只要用同樣的檔名蓋掉就好**，
  程式碼一行都不用改；檔案缺席時會自動退回瀏覽器語音合成。
- 語音一開口，配樂／環境／音效自動 duck 下去，講完淡回來。

重新產生語音：

```bash
pip install edge-tts
python tools/make_voice.py        # 台詞表就在這支檔案裡
```

## 秘密（夜光島）

不寫在畫面上，只有真的玩才會遇到（存檔會記住你發現過哪些）：

1. 連續戳嚕米五下。
2. 貝殼海灘右下角那顆石頭，戳七下。
3. 把整座島點亮之後，抬頭看天空。
4. 燈籠收藏頁裡，照順序把收到的光靈全部戳一遍。

## 已知取捨

- **一座島幾題、一晚幾段風沒有依據**：目前是 5～6 題／5～7 段。
  「6 歲一次玩多久」查不到可信來源，網路流傳的「每歲 2-3 分鐘」找不到原始出處 ——
  這兩個數字只能靠看她玩來校準，不要假裝有依據。
- **道具不做背包管理**：擁有的道具全部自動帶著（畫面最多顯示 4 個）。
  「帶哪個道具」的選擇被前移到寶箱：兩件挑一件。六歲不該管理背包。
- **語音是 TTS 不是真人**：架構已經留好替換位（見上），但現在的聲音仍聽得出合成感。
- **效能只在桌機 Chromium 量過**（1080p 視窗、390×844 模擬手機，穩定 60fps）。
  真機 GPU 特性不同，尤其舊 Android 的 SVG 合成較慢，實機仍值得再看一次。
- **iOS 低耗電模式**下 `requestAnimationFrame` 會降到 30fps，動畫會鈍一點，玩法不受影響。
- **無障礙**：這是給還不識字的孩子玩的觸控玩具，介面刻意幾乎無文字，
  因此沒有做鍵盤導覽與螢幕閱讀器標註；`prefers-reduced-motion` 有處理。
