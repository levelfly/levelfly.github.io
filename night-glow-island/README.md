# 嚕米的夜光島

給 3～6 歲小朋友的數字冒險。手機／平板優先，桌機也能玩。

---

## 怎麼跑

需要一個靜態伺服器（因為用了 ES modules，直接開 `index.html` 會被瀏覽器擋）。

```bash
cd 夜光島
python serve.py            # → http://127.0.0.1:8777
```

`serve.py` 只是關掉快取的 `http.server`，換成任何靜態伺服器都可以：

```bash
npx serve .        # 或
php -S 127.0.0.1:8777
```

**手機實機測試**：跟電腦同一個 Wi-Fi，把 `serve.py` 最後一行的 `127.0.0.1` 改成 `0.0.0.0`，
再用手機開 `http://<電腦IP>:8777`。或用 `/quick-tunnel` 開一條臨時 https 網址
（iOS Safari 的音訊在 http 也能跑，但加到主畫面全螢幕玩比較好）。

第一次進來會停在一盞提燈上——**點它**（瀏覽器規定要有一次真實觸碰才准出聲，
這一下同時也是遊戲的第一個動作）。

### 開發捷徑

```
?go=marsh|cove|grove|cliff|light     直接跳進某個地點
?go=map|lantern|finale|title         直接跳場景
?go=map&lit=marsh,cove               順便指定哪些地方已經點亮
```

## 玩什麼

夜光島的光被吹散了。小獸嚕米提著一盞空燈籠，需要小朋友幫忙把光找回來。
島上五個地方，每個地方 4～5 題，答完就永久亮起來，並帶回一隻光靈。
五個地方都亮 → 燈塔點燃 → 結局。

兩根學習支柱（題型會隨地點與表現輪替）：

| 題型 | 做什麼 | 出現在 |
|------|--------|--------|
| `listen` | 聽到一個數字，從畫面裡找到那個數字 | 貝殼海灘、星星懸崖、燈塔 |
| `count` | 看到一群東西，選出對應的數字 | 螢火沼澤、果實樹林、燈塔 |
| `quantity` | 聽到數字，選出「那麼多」的一群 | 燈塔 |

**難度會自己走**：連錯兩題 → 選項降到 2 個並提示正解；連對三題 → 選項升到 4 個、數字範圍放大。
答錯沒有紅色、沒有叉叉、沒有分數，那個東西只是害羞地縮一下，永遠可以再試。

**數數是可以用手的**：`count` 題裡每隻螢火蟲／每顆果子都能戳，戳一個亮一個，
木琴音一階一階往上，同時報「一、二、三……」。這是鷹架，不是答案。

```

serve.py              本機開發伺服器（關快取）
styles/
  base.css            重置、舞台、安全區、紙紋
  game.css            HUD、紙卡、標題、收藏頁
src/
  main.js             進入點：量舞台 → 載語音 → 等一次觸碰 → 開場
  game.js             外殼：場景切換、常駐的嚕米、HUD、打噴嚏的秘密
  core/
    stage.js          響應式座標系（field 百分比 → 像素，直橫向重排）
    ticker.js         單一 rAF 迴圈
    spring.js         彈簧物理（所有「有重量」的動作都走這裡）
    pointer.js        觸控優先的點擊（按下就回饋、容忍手抖、防重複觸發）
    audio.js          Web Audio：程序化音效 + 配樂 + 語音佇列與 ducking
    store.js          localStorage 存檔（收藏、輪數、秘密）
    rng.js            有種子的亂數
  art/
    paper.js          撕紙邊 / 紙纖維 / 光暈濾鏡、有機形狀產生器
    scenery.js        程序化剪紙場景（八個地點各一個 builder）
    lumi.js           主角骨架：頭、耳、眼皮、瞳孔、尾巴、提燈
    glyphs.js         手寫感數字 0–10（純路徑，不用任何字型）
    props.js          可以被戳的東西：螢火蟲、貝殼、果實、星星、數字牌
    particles.js      canvas 粒子（浮塵、光爆、飛向燈籠的光）
  data/

    glowbugs.js       12 隻光靈與獎勵抽取
  scenes/
    title.js  map.js  level.js  lantern.js  finale.js
assets/voice/         73 段中文語音（mp3）+ manifest.json
```

### 沒有外部素材

畫面上每一個像素都是程式畫的：SVG 路徑 + `feTurbulence` 撕紙濾鏡 + Canvas 粒子。
沒有圖片檔、沒有字型檔、沒有 emoji、沒有第三方函式庫。
好處不只是輕——**程序化場景會動**（草會晃、水會湧、星星會呼吸），
而且直握橫握是「重新構圖」而不是「把桌面版縮小」。

### 效能：撕紙感放在幾何裡，不放在濾鏡裡

第一版跑起來只有 **12 fps**。逐層量測（`display:none` 一層測一次）指向同一個原因：
場景是一整張大 SVG，只要裡面有任何東西在動，整張就會重畫——**連同裡面每一個
`feTurbulence` 濾鏡**。當時場景裡有 60 個帶濾鏡的元素。

四刀砍到 **60 fps**，畫面幾乎沒有損失：

1. **場景與角色不用位移濾鏡**——不規則邊緣本來就長在 `tornEdge()` / `blob()` 產生的
   幾何裡，濾鏡只是再糊一層看不太出來的絨毛。濾鏡留給不會每幀重畫的小元件（數字牌、道具）。
2. **霧的柔邊改用漸層**而不是 `feGaussianBlur`——霧每幀都在飄，帶著模糊跑等於每幀重算一次大面積模糊。
3. **合併每幀的屬性寫入**：蘆葦分兩束整組搖（不是每根各搖）、水帶與浪頭同一個 `<g>`、
   只有最上面兩條水帶會動、會眨的星星設上限 18 顆。
4. **粒子改用烘好的 sprite**：每顆粒子即時 `createRadialGradient` 是手機殺手，
   現在每個顏色只烘一次 64×64 的小 canvas，之後都只是 `drawImage`。

道具的光暈也改成「彈簧停下來就不再寫屬性」——否則每幀寫一次 `opacity`
會讓整顆 prop 連同它的濾鏡重畫。

### 聲音

- **音效／配樂**：Web Audio 即時合成。木琴、玻璃風鈴、泡泡、光的綻放；
  配樂是一組緩慢的五聲和聲墊 + 隨機灑落的木琴音，每個地點換根音與音色，永遠不會 loop 到膩。
- **語音**：`assets/voice/*.mp3`，由 `manifest.json` 對照 id → 檔案。
  目前是 edge-tts 的 `zh-TW-HsiaoChenNeural`。**要換成真人錄音，只要用同樣的檔名蓋掉就好**，
  程式碼一行都不用改；檔案缺席時會自動退回瀏覽器語音合成。
- 語音一開口，配樂／環境／音效自動 duck 下去，講完淡回來。

重新產生語音：

```bash
pip install edge-tts
python tools/make_voice.py        # 台詞表就在這支檔案裡
```

## 秘密

不寫在畫面上，只有真的玩才會遇到（存檔會記住你發現過哪些）：

1. 連續戳嚕米五下。
2. 貝殼海灘右下角那顆石頭，戳七下。
3. 把整座島點亮之後，抬頭看天空。
4. 燈籠收藏頁裡，照順序把收到的光靈全部戳一遍。

## 已知取捨

- **語音是 TTS 不是真人**：架構已經留好替換位（見上），但現在的聲音仍聽得出合成感。
- **效能只在桌機 Chromium 量過**（1080p 視窗、390×844 模擬手機，穩定 60fps）。
  真機 GPU 特性不同，尤其舊 Android 的 SVG 合成較慢，實機仍值得再看一次。
- **iOS 低耗電模式**下 `requestAnimationFrame` 會降到 30fps，動畫會鈍一點，玩法不受影響。
- **無障礙**：這是給還不識字的孩子玩的觸控玩具，介面刻意幾乎無文字，
  因此沒有做鍵盤導覽與螢幕閱讀器標註；`prefers-reduced-motion` 有處理。
