# Design: 台南旅遊全方位指南網站

## Context

用戶需要一個全面的台南旅遊參考網站，供全家旅遊使用。現有兩個分散的網頁需要整合，並擴充更多資訊。網站需要適合手機長時間瀏覽，且資料要詳盡豐富。

### 約束條件
- 靜態網站（GitHub Pages）
- 無後端伺服器
- 私人使用，圖片可本地儲存
- 需支援離線瀏覽

## Goals / Non-Goals

### Goals
- 建立七大核心模組的完整台南旅遊指南
- 手機優先的響應式設計
- 長時間瀏覽不疲勞的 UI
- 快速載入、流暢瀏覽
- 豐富的圖片視覺體驗
- 智慧分類與篩選

### Non-Goals
- 不需要用戶帳號系統
- 不需要即時資料更新
- 不需要評論功能
- 不建立獨立後台

## Decisions

### 1. 技術選型

**決定**：純靜態網頁（HTML + CSS + Vanilla JS）

**原因**：
- GitHub Pages 免費託管
- 無需伺服器維護
- 載入速度快
- 離線可用

**替代方案考慮**：
- React/Vue SPA：過度工程，增加複雜度
- Jekyll/Hugo：學習成本，維護難度

### 2. 資料結構

**決定**：使用 JSON 檔案儲存資料，JavaScript 動態載入

```
data/
├── attractions.json    # 景點資料
├── restaurants.json    # 餐廳資料
├── snacks.json         # 小吃資料
├── nightmarkets.json   # 夜市資料
├── drinks.json         # 飲料店資料
├── hotels.json         # 住宿資料
├── transport.json      # 交通資料
└── itineraries.json    # 推薦行程
```

### 3. UI/UX 設計

**決定**：卡片式設計 + 底部導航 + 分類標籤

**設計原則**：
- 大字體（16px 基準）
- 高對比度配色
- 充足的點擊區域（最小 44px）
- 圖片懶載入
- 無限滾動或分頁
- 固定底部導航

**配色方案**：
- 主色：#FF6B35（台南夕陽橘）
- 輔色：#004E89（深藍）
- 背景：#F7F7F7（淺灰）
- 文字：#333333

### 4. 分類系統

**決定**：兩層分類 + 多標籤篩選

**主分類**：
1. 景點（親子/文青/古蹟/自然/園區）
2. 美食（餐廳/小吃/夜市/飲料/甜點）
3. 住宿（飯店/民宿/親子住宿）
4. 交通（租車/大眾運輸/停車）
5. 行程（一日遊/兩日遊/主題路線）
6. 實用（伴手禮/注意事項/地圖）

**篩選標籤**：
- 區域：中西區/安平區/東區/北區/南區/其他
- 特性：親子友善/寵物友善/無障礙/有停車場
- 價位：$/$$/$$$/$$$$
- 推薦：米其林/必比登/在地人推薦

### 5. 圖片策略

**決定**：本地儲存 + WebP 格式 + 懶載入

**圖片規格**：
- 縮圖：300x200px，WebP，< 30KB
- 大圖：800x600px，WebP，< 100KB
- 使用 loading="lazy" 延遲載入

## Risks / Trade-offs

| 風險 | 影響 | 緩解措施 |
|------|------|----------|
| 圖片版權 | 法律風險 | 私人使用、不商用 |
| 資料過時 | 用戶體驗 | 標註更新日期、定期維護 |
| 檔案過大 | 載入慢 | 圖片壓縮、分頁載入 |
| 手機相容性 | 瀏覽問題 | 測試多種裝置 |

## Migration Plan

1. 建立新目錄 `tainan-guide/`
2. 保留原有 `tainan-family-trip/` 和 `tainan-car-rental/`
3. 從原有網頁提取優質內容
4. 逐步建立新網站
5. 完成後可考慮將舊網頁重定向到新網站
