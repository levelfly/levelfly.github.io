# Spec: 台南旅遊全方位指南

## ADDED Requirements

### Requirement: 七大核心模組

系統 SHALL 提供以下七大核心內容模組：
1. 景點指南 - 親子景點、文青景點、古蹟歷史、自然生態、特色園區
2. 美食餐廳 - 在地餐廳、特色料理、米其林推薦
3. 小吃夜市 - 古早味小吃、排隊名店、夜市攻略
4. 飲料甜點 - 手搖飲、咖啡廳、冰品甜點
5. 住宿推薦 - 親子飯店、特色民宿、商務旅館
6. 交通指南 - 租車比較、大眾運輸、停車資訊
7. 行程規劃 - 一日遊、兩日遊、主題路線

#### Scenario: 用戶瀏覽景點模組
- **WHEN** 用戶點選景點分類
- **THEN** 顯示所有景點卡片，包含圖片、名稱、簡介、標籤

#### Scenario: 用戶瀏覽美食模組
- **WHEN** 用戶點選美食分類
- **THEN** 顯示所有美食店家卡片，包含圖片、店名、特色、評價

---

### Requirement: 手機優先響應式設計

系統 SHALL 採用手機優先的響應式設計，確保在各種螢幕尺寸下都能良好顯示。

**設計規格**：
- 最小支援寬度：320px
- 最大內容寬度：1200px
- 基準字體：16px
- 最小點擊區域：44x44px

#### Scenario: 手機瀏覽
- **WHEN** 用戶在手機上瀏覽（螢幕寬度 < 768px）
- **THEN** 顯示單欄式卡片佈局，底部固定導航列

#### Scenario: 平板瀏覽
- **WHEN** 用戶在平板上瀏覽（768px <= 螢幕寬度 < 1024px）
- **THEN** 顯示雙欄式卡片佈局

#### Scenario: 桌面瀏覽
- **WHEN** 用戶在桌面上瀏覽（螢幕寬度 >= 1024px）
- **THEN** 顯示三欄式卡片佈局，側邊導航

---

### Requirement: 分類與篩選系統

系統 SHALL 提供兩層分類導航和多標籤篩選功能。

**主分類**：景點、美食、小吃、飲料、住宿、交通、行程

**篩選維度**：
- 區域：中西區、安平區、東區、北區、南區、其他
- 特性：親子友善、寵物友善、無障礙、有停車場
- 價位：$（平價）、$$（中等）、$$$（中高）、$$$$（高價）
- 推薦：米其林、必比登、在地人推薦、部落客推薦

#### Scenario: 用戶篩選親子景點
- **WHEN** 用戶在景點分類下選擇「親子友善」標籤
- **THEN** 只顯示標註為親子友善的景點

#### Scenario: 用戶多重篩選
- **WHEN** 用戶同時選擇「中西區」和「米其林推薦」
- **THEN** 顯示位於中西區且獲得米其林推薦的店家

---

### Requirement: 卡片式資訊展示

系統 SHALL 使用卡片式設計展示各類資訊，每張卡片包含：
- 主圖片（16:9 或 4:3 比例）
- 名稱標題
- 簡短描述（最多 50 字）
- 分類標籤
- 評價指標（如適用）
- 地址與聯絡資訊

#### Scenario: 顯示景點卡片
- **WHEN** 系統渲染景點卡片
- **THEN** 卡片顯示景點圖片、名稱、簡介、區域標籤、適合對象標籤

#### Scenario: 顯示美食卡片
- **WHEN** 系統渲染美食卡片
- **THEN** 卡片顯示店家圖片、店名、招牌菜、價位、推薦標籤、營業時間

---

### Requirement: 圖片展示與載入

系統 SHALL 提供豐富的圖片視覺體驗，並優化載入效能。

**圖片規格**：
- 縮圖：WebP 格式，300x200px，< 30KB
- 大圖：WebP 格式，800x600px，< 100KB
- 備援格式：JPEG

#### Scenario: 圖片懶載入
- **WHEN** 頁面載入時
- **THEN** 只載入視窗內的圖片，其餘圖片延遲載入

#### Scenario: 圖片載入失敗
- **WHEN** 圖片載入失敗
- **THEN** 顯示預設佔位圖片

---

### Requirement: 搜尋功能

系統 SHALL 提供全站搜尋功能，支援關鍵字搜尋。

#### Scenario: 關鍵字搜尋
- **WHEN** 用戶輸入「牛肉湯」並搜尋
- **THEN** 顯示所有包含「牛肉湯」關鍵字的店家和相關內容

#### Scenario: 空搜尋結果
- **WHEN** 搜尋無符合結果
- **THEN** 顯示「找不到相關內容」提示，並建議相關分類

---

### Requirement: 行程規劃展示

系統 SHALL 提供預設的推薦行程，幫助用戶規劃旅遊。

**行程類型**：
- 一日遊路線（含時間軸）
- 兩日遊路線
- 主題路線（美食之旅、親子之旅、古蹟之旅等）

#### Scenario: 顯示一日遊行程
- **WHEN** 用戶查看一日遊行程
- **THEN** 以時間軸方式顯示建議景點和用餐地點，包含預估時間和交通方式

---

### Requirement: 離線可用

系統 SHALL 作為靜態網站部署，支援基本的離線瀏覽。

#### Scenario: 離線瀏覽已載入內容
- **WHEN** 用戶在離線狀態下瀏覽已載入的頁面
- **THEN** 頁面內容和已快取的圖片正常顯示

---

### Requirement: 底部導航列

系統 SHALL 在手機版本提供固定底部導航列，方便用戶快速切換主要分類。

**導航項目**：首頁、景點、美食、住宿、行程

#### Scenario: 底部導航切換
- **WHEN** 用戶點擊底部導航的「美食」
- **THEN** 頁面滾動或切換至美食分類，導航項目高亮顯示

---

### Requirement: 資料結構標準化

系統 SHALL 使用 JSON 格式儲存所有資料，遵循統一的資料結構。

**景點資料結構**：
```json
{
  "id": "string",
  "name": "string",
  "category": "string",
  "subcategory": "string",
  "district": "string",
  "address": "string",
  "phone": "string",
  "hours": "string",
  "description": "string",
  "tags": ["string"],
  "images": ["string"],
  "rating": "number",
  "price": "string",
  "coordinates": { "lat": "number", "lng": "number" }
}
```

#### Scenario: 載入 JSON 資料
- **WHEN** 頁面載入時
- **THEN** JavaScript 從 JSON 檔案讀取資料並渲染至頁面
