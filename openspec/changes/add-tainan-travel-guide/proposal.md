# Change: 建立台南旅遊全方位指南網站

## Why

現有兩個台南相關網頁（`tainan-family-trip` 親子旅遊攻略、`tainan-car-rental` 租車指南）內容分散，且資料需要更新和擴充。需要整合現有資源，並透過廣泛的網路搜尋蒐集最新、最全面的台南旅遊資訊，建立一個適合手機長時間瀏覽的全方位台南旅遊參考網站。

### 蒐集方法

```
階段一：廣泛搜尋
├── 使用 Exa 搜尋引擎進行深度搜尋
├── 關鍵字組合：台南 + [類別] + 2024/2025 + 推薦/必吃/必去
├── 每個類別至少搜尋 3-5 次不同關鍵字
└── 收集 URL 和摘要資訊

階段二：深度爬取
├── 針對高品質來源進行詳細資料提取
├── 提取：店名、地址、電話、營業時間、價位、特色、圖片
├── 使用 Playwright/Chrome DevTools 處理動態網頁
└── 下載圖片至本地

階段三：交叉驗證
├── 多來源比對確認資訊正確性
├── Google Maps 驗證地址和營業狀態
├── 標註資料來源和更新日期
└── 移除已歇業或資訊不符的店家

階段四：分析整理
├── 建立統一的 JSON 資料結構
├── 分類標籤標準化
├── 計算推薦指數（綜合評價、曝光度、獨特性）
└── 規劃推薦行程路線
```

### 資料品質標準

| 欄位 | 必要性 | 驗證方式 |
|------|--------|----------|
| 店名/景點名 | 必填 | - |
| 地址 | 必填 | Google Maps 驗證 |
| 營業時間 | 必填 | 多來源交叉驗證 |
| 電話 | 選填 | - |
| 價位範圍 | 必填 | 標準化為 $/$$/$$$/$$$$ |
| 特色描述 | 必填 | 至少 30 字 |
| 分類標籤 | 必填 | 使用預定義標籤 |
| 圖片 | 必填 | 至少 1 張，建議 3 張 |
| 推薦來源 | 選填 | 米其林/部落客/在地人 |
| 更新日期 | 必填 | 自動記錄 |

## What Changes

### 新功能
- 建立整合式台南旅遊指南網站（`tainan-guide/`）
- 涵蓋七大核心模組：景點、美食、小吃夜市、住宿、交通租車、行程規劃、實用資訊
- 手機優先的響應式設計，優化長時間瀏覽體驗
- 豐富的圖片資源（下載至本地）
- 智慧分類與篩選功能
- 地圖整合與路線規劃

### 資料來源
- 合併現有 `tainan-family-trip` 和 `tainan-car-rental` 的優質內容
- 透過網路搜尋蒐集 2024-2025 最新資訊
- 米其林必比登、在地人推薦、部落客攻略等多元來源

### 設計目標
- 適合家庭旅遊使用
- 資料詳盡且易於查找
- 視覺豐富、閱讀舒適
- 離線可用（靜態網頁 + 本地圖片）
